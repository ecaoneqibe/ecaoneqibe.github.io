1. 解压与安装

下载完压缩包后，请确保使用 WinRAR 或 7-Zip 进行解压。CS1.6 的单机版通常是一个免安装的绿色版本。

解压后，直接双击 cstrike.exe 即可运行游戏。首次运行可能需要几秒钟加载资源。

2. 运行游戏

启动游戏后，会直接进入主菜单。由于是单机版，您无需输入 Steam 账号密码。

点击“开始游戏”选择“反恐精英”模式。在创建房间时，选择“局域网游戏”或直接在“单人游戏”模式下进行。

3. 添加机器人

进入游戏后，在控制台（按 ` 键打开）输入 mp_teambalance 0 并回车。

输入 sv_cheats 1 开启作弊模式。

输入 bot_kick 清除所有玩家。

输入 bot_add_t 10（添加10名恐怖分子）或 bot_add_ct 10（添加10名反恐精英）。

输入 mp_roundtime 60 将回合时间延长至60分钟。

输入 mp_restartgame 1 重启游戏开始对战。

4. 模组与地图安装

将下载的 .bsp 地图文件放入 cstrike/maps 文件夹中。

将 .mdl 或 .mdl.gz 模型文件放入 cstrike/models 文件夹中。

部分版本需要将 liblist.gam 文件标记为“只读”才能加载地图。

5. 常见报错处理

闪退问题： 确保显卡驱动已更新，并关闭后台占用内存过多的软件。尝试右键游戏图标选择“以管理员身份运行”。

找不到文件： 检查是否将文件放入了正确的 cstrike 目录下，而不是解压到了多层文件夹中。

常见问题 (FAQ)

CS1.6 机器人版支持多人联机吗？
是的，大部分“带机器人下载”的版本都支持局域网联机。您可以在游戏创建房间中选择“局域网游戏”，然后在其他电脑上通过局域网连接进入。
下载的版本需要联网吗？
单机版（免安装版）完全不需要联网即可游玩。但是，为了体验中文语音包或下载最新的地图模组，可能需要连接网络。
如何提高机器人的智商？
在控制台输入 bot_difficulty 3 可以将机器人难度设置为最高（3）。此外，使用专门的“AI增强版”安装包通常会包含更高级的脚本。
游戏运行很卡怎么办？
在控制台输入 fps_max 99 可以限制帧数上限以优化性能。降低游戏内的“视频设置”中的分辨率和阴影效果也能有效提升帧数。
